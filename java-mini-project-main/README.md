# Java Mini Project – Quiz Application

## Project Overview
A Java-based quiz application that includes user login,
quiz rules, score calculation, and a results display.

## Team Members
- Palak Goel
- Kashish goel

## Technologies Used
- Java
- Java Swing 
- Object-Oriented Programming

## Project Files
- `Login.java` – User login
- `Quiz.java` – Quiz functionality
- `Rules.java` – Quiz instructions
- `Score.java` – Score calculation and results

## How to Run
1. Clone or download this repository.
2. Open the Java files in your IDE.
3. Compile and run the main class.
